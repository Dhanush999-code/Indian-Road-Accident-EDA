# Indian Road Accident Data Analysis (EDA)

## Project Overview
This project focuses on performing Data Preprocessing and Exploratory Data Analysis (EDA) on an Indian Road Accident dataset. The objective is to identify patterns and trends in road accident records using Python and data visualization techniques.

## Dataset
- Dataset: Indian Road Accident Dataset
- Source: Kaggle
- Data includes accident dates, locations, severity, weather conditions, visibility, road types, casualties, and other relevant attributes.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Preprocessing
- Loaded and explored the dataset.
- Checked and handled missing values.
- Checked for duplicate records.
- Examined data types and statistical summaries.
- Prepared date-related features for time-based analysis.

## Key Findings
1. The first five months of the year recorded a higher number of accidents in the combined monthly analysis.
2. More than 10,000 accident records were classified as minor accidents.
3. A higher number of accidents were recorded under lower visibility conditions.
4. Correlation analysis was performed to examine relationships between numerical variables.
5. Accident distributions across weekdays, hours, weather conditions, and cities were relatively balanced.

## Project Structure
- `Indian_Road_Accident_EDA.ipynb` – Jupyter Notebook containing the complete analysis.
- `EDA_Report.pdf` – Summary of the analysis and key findings.

4. Run the cells to reproduce the analysis.

## Conclusion
This project helped identify patterns in road accident records through data preprocessing, statistical analysis, and visualization. It demonstrates the use of Python libraries for exploratory data analysis before machine learning model development.
